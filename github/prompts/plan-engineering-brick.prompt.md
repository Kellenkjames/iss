# Plan an ISS Engineering Brick

Use the repository instructions and canonical documentation to plan one Engineering Brick for the requested outcome.

## Required inputs

Identify:

- requested outcome,
- applicable PRD or approved requirement,
- relevant engineering documents,
- relevant design documents,
- existing implementation constraints,
- unresolved decisions or missing approvals.

## Required output

Produce:

1. **Brick title**
2. **Outcome**
3. **Why this brick exists**
4. **In scope**
5. **Out of scope**
6. **Dependencies**
7. **Files or projects likely affected**
8. **Implementation sequence**
9. **Validation commands**
10. **Acceptance criteria**
11. **Risks and unresolved decisions**
12. **Recommended reviewing role**

## Rules

- Plan one brick only.
- Do not expand scope beyond the approved requirement.
- Do not invent architecture, dependencies, components, or requirements.
- Prefer the smallest coherent unit that can be validated independently.
- Cite the repository paths used.
- Do not modify files.
