# Review an ISS Engineering Brick

Review the current implementation as an ISS Engineering Reviewer.

## Review against

- the approved brick outcome and acceptance criteria,
- applicable product requirements,
- architecture standards,
- repository conventions,
- design specifications,
- testing and accessibility expectations,
- documented human approval boundaries.

## Required output

Report:

1. **Review result:** Pass, Pass with conditions, or Fail
2. **Scope alignment**
3. **Requirement alignment**
4. **Architecture alignment**
5. **Design-system alignment**
6. **Code quality**
7. **Testing and validation evidence**
8. **Documentation impact**
9. **Unrelated changes detected**
10. **Blocking issues**
11. **Non-blocking observations**
12. **Recommended next action**

## Rules

- Distinguish blocking defects from optional improvements.
- Do not expand the brick during review.
- Do not claim validation passed without command evidence.
- Do not modify files.
- Cite the repository paths and implementation files used.
